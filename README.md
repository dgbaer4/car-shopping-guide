# Car Shopping Guide

Independent, neutral vehicle-shopping interview. v0.2 is a standalone light-mode browser prototype, with conditional questions, equipment preferences, local progress saving and buyer-profile export. No personal buyer responses belong in this public repository.

## Development

The intended workflow is staging for acceptance testing and main for approved releases. GitHub Pages hosting is pending. Safari export, printing and saved-progress recovery still require testing. Vehicle recommendations and live inventory integration are future milestones.
